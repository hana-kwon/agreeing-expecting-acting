# Later analyses (proposal Section 3, appendix A9)

Each folder holds the code of one exploratory analysis in `code/` and its aggregate result tables in `tables/`.

- Respondent-level survey rows, firm-level customs and postings rows, and statement text from the commercial archive are not included, so most scripts do not run from this repository alone. Private locations appear as placeholders such as `PRIVATE_DATA_ROOT`.
- Code is released as run, with comments and paths edited for anonymity. Draws from placebo runs and passage-level check sheets are left out.
- Folder `55_review_reruns_261102` gives the message comparison in the same samples (Table A29), the same-owner slopes (Table A30), and the market windows (Table A31).
- Folders `53`, `54`, `50` give A9.4 and A9.5; `46`, `47`, `48`, `52` give A9.6.

All of these analyses are exploratory.
